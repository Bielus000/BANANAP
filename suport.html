Manual d'Instruccions

Com funciona BANANAP? Aprèn a treure-li el màxim profit al teu controlador Arduino per crear la millor experiència audiovisual.

La Consola Física

  • Botó 1: Kick (Bombo) i esclat de llum (Flash).
  • Botó 2: Snare (Caixa) i línies radials.
  • Botó 3: Pluck i expansió d'anells.
  • Botó 4: FM Bell i patró de punts ziga-zaga.
  • Fader 1: Filtre de so (Lowpass filter cutoff).
  • Fader 2: Selector de paletes de color (15 paletes diferents).
  • Fader 3: Mida de les formes visuals (Escala global).
  • Fader 4: Reverb global (Efecte de sala).
  • Fader 5: Gruix de les línies visuals dibuixades.

Resolució de Problemes

El botó "Connect Arduino" no fa res?

Assegurat d'estar fent servir els navegadors Google Chrome o Microsoft Edge en PC o Mac. Safari i Firefox no són compatibles amb la tecnologia Web Serial.

Està connectat però no reacciona?

Comprova que el teu Arduino estigui funcionant a la mateixa velocitat que la web (115200 bauds). També verifica que el cable USB permeti transmissió de dades i no només càrrega d'energia.

Sona distorsionat o va molt lent?

El sistema de síntesi de so en temps real requereix capacitat de processament. Tanca altres pestanyes pesades i assegurat que el teu navegador utilitza l'acceleració per maquinari.
